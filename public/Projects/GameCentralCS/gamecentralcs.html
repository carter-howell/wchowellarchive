GameCentralCS

Game Project | 2020 | Completed

Unreal EngineHTML5FirebaseGame Development

A Firebase-hosted collection of Unreal Engine HTML5 game experiments, including a custom Flappy Fish game.

Implementation

I built the games in Unreal Engine 4.24.3, then hosted the exported HTML5 files through Firebase. Because official HTML5 export support was removed after this Unreal Engine version, I used community documentation and support files to complete the build and deployment process.

Reference: UnrealEngineHTML5. Live site: gamecentralcs.web.app.

Flappy Fish

Flappy Fish started from a tutorial-style Flappy Bird clone and then grew into a custom version with original pixel-art assets. I built the fish, a friend helped with background and obstacle art, and I added the scoring overlay and game logic in Unreal Blueprint.
