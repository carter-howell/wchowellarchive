Hollow Clock

EE Project | 2022 | Completed

RP2040Stepper Motor3D PrintingMagnets

A 3D-printed magnetic clock build using a Waveshare RP2040 Zero, a stepper motor, and a compact driver board.

Build Summary

This project followed an existing hollow-clock design and gave me practice with embedded hardware assembly, 3D-printed mechanical parts, and stepper-motor control. The clock uses magnets in the hand and outer rim so the hand can move while the center appears open.

The electronics use a Waveshare RP2040 Zero board soldered directly to a small stepper motor driver. The compact layout keeps the control electronics hidden inside the printed housing.

Reference build: Hollow Clock V.
