The Firebase-hosted engineering portfolio and project archive used to present my resume, project documentation, and technical work.

Purpose

I built this site to keep my engineering and software projects organized in one public archive. It now functions as both a portfolio and a resume companion, with project pages, SEO metadata, downloadable resume assets, and a static Firebase deployment.

Implementation

The site is written with HTML, CSS, and JavaScript and hosted on Firebase. The homepage can populate resume highlights from a Word document, while the visible resume download points to a PDF. Project pages use shared styling, social preview metadata, and structured data on the main engineering projects.
